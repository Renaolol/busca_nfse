# LLM Development Guide

## Regras operacionais

1. Ler `AGENTS.md` e `docs/` antes de codar.
2. Para mudancas em DANFSE/PDF, ler obrigatoriamente `docs/danfse-pdf-guide.md`.
3. Atualizar testes, OpenAPI e docs em cada mudanca.
4. Manter migrations em mudancas de banco.
5. Evitar acoplamento com API oficial em testes.

## Definicao de entrega minima por tarefa

- Codigo compila
- Testes relevantes passam
- Contratos API atualizados
- Documentacao atualizada
